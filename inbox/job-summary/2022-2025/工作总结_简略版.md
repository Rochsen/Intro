# 罗浩森 2022–2025 工作项目总结（简略版）

> 依据 2022–2024 年终总结 PPT 与 2025 年月度工作记录整理；每项目一行，按「内容 → 难题 → 解法 → 结果」压缩表述，原始资料缺失的条目不列出。

## 2022（6–12月）· 产品技术部 · 生信助理工程师

- **实验室数据统计流程搭建**：搭建基于多表采集数据的统计绘图流程；难题：审核组解读困难、单位报告自动化未构建 → 打磨模块并组织阶段性成果分享会对齐需求；结果：12 月完成分享会，为次年 PGS 质控报告产品线奠基。
- **WES 分析流程搭建**：走通 Fastp → BWA → GATK（去重/Call 变异）→ ANNOVAR 注释（Clinvar 自建库 + Intervar 爬虫库）全流程；结果：完成流程雏形，后续年份持续优化。

## 2023 · 研发中心-生物信息部 · 生物信息助理工程师

- **PGS 送检单位质控报告**：按送检单位/实验室（序源、番禺）按月产出质控报告；难题：指标与绘图样式未定、批量产出难 → 与实验室沟通定样式、实验室提供模板、构建自动化程序批量产出；结果：7 月起每月 8 号交付，当年交付 5 次。
- **WES 流程构建与优化**：更新注释数据库（avsnp150/clinvar_20221231/cosmic70）、新增 VEP 多转录本注释合并、位点排序（答案位点进前 20%）、统计质控、表型过滤/标注、家族位点标注；难题：注释耗时 6h 占比 50–60% → 多进程注释降至 2h；Picard 标记重复 CPU 高占用 → Sambamba 平替（40min→4min，位点一致性 99%）；低质量致病位点 Call 不出 → GATK 加参数找回（P-2 星位点）；BWA vs SNAP 评估后暂不替换；亮点：注释提速 50–60%，"上午分析、下午出结果"。
- **ECS 携带者筛查流程**：基于 Gencode 构建 hg19/hg38 Panel 索引表，WES 后全位点 Panel 标注 + 仅 Panel 位点输出；结果：满足双输出需求。
- **样本数据管理**：制定《客户样本数据传输至公司服务器标准作业指导书》；结果：全年完成 28 例样本数据下载。
- **工具模块（6 项）**：芯片 SNP 区域筛选统计（判断 PGS 可检性）、基因外显子占比统计（评估入 Panel 价值）、核型三体/单体/嵌合 CNV 注释升级、ClassifyCNV 测试（ACMG 五级）、CHPO 表型爬虫（辅助表型过滤）、销售业务样本量统计（交付 6 次，节省人工）。

## 2024 · 生物信息部 · 生物信息分析工程师

- **业务分析与数据管理**：数据传输方法体系化（ossutil/NAS/网盘/tosutil + SOP 更新）；全年 63 例 WES 样本管理与分析；PGS 上游指标探索（Y 信号判定规则、相关性 0.3；胚胎数量与女方年龄负相关）。
- **DeepVariant 评估**：对比 HaplotypeCaller（速度/一致性/致病位点评级）；结果：RefCall 获更多致病位点，可接纳替代 GATK。
- **VEP 替换 ANNOVAR**：难题：ANNOVAR 丢弃 0/0 基因型位点 → VEP + 自建注释程序平替 refGene/dbnsfp33a/人群频率库（Consequence→严重性分值映射、PP3/BP4 字段保持）；验证：前 30–40% 位点一致性较高、P/LP/VUS 数量无明显差距；结果：确认替换。
- **注释功能增强（4 项）**：本地位点频率库（每批样本自动滚动更新，辅助新发突变判断）、表型关联性文本提取（按句截取匹配内容）、位点评价指标（Priority/Quality/Location 三维）、全染色体深度绘图（samtools+tbi，辅助性别推断）。
- **GO/KEGG 富集分析**：支撑 14 例医学科研样本；产出点状图与 DAG 图（KEGG 通路图待开发）。
- **业务数据统计软件（软著①）**：三模块——PGS 质控报告、人员实验室质控报告（docx 绘图）、销售业务统计；远程控制器"执行+传输"，支持自定义时间/单位；结果：9 月获软著证书。
- **WES-NGS 分析流程软著（软著②）**：结果：11 月获软著证书。
- **CIP 前端起步**：10 月起参与常规临检系统前端；结果：全 124 需求中个人完成 53 个。
- **其它**：生信云工具数据挖掘（爬虫→Excel→统计）；CNV 致病性分级流程（ACMG 分享 + Content/Gene 评分，后暂停）；WES 目标区域 CallCNV 调研（ExomeDepth/XHMM 未检出，分析原因后暂停）。

## 2025 · 生物信息部

- **临床检验数据清除软件 + SOP**：覆盖微信聊天文件、精子分析系统（bat 脚本 + 空拷贝）、双子星仪器现场调研等；优化 GUI 与搜索性能、编写 SOP；结果：2–3 月交付，回访无问题反馈。
- **WES 流程重构**：难题：表型标注未嵌入流程、质控分散 → 表型注释嵌入批处理 + 携筛 Panel 筛选合并（防窜流）+ shell 转 Snakemake（WES.smk + 固定配置文件）+ 204 服务器迁移（Docker/conda/性能测试/频率库嵌入）；结果：测试通过并嵌入 iap 脚本，204 适配 hg19 生产。
- **WES hg38 转化**：下载构建 WBBC/gnomAD/AlphaMissense 索引，缺库位点转 hg19 测试通过，开发 gwasCatalog tabix 查找；结果：通过单/双端及不同分析需求测试。
- **三代测序下载处理自动化（TGS）**：多渠道选型（火山云自动化 + 非火山云人工下载生成 sample.json），持续修补边界情况（括号/横杠/中文名/md5）；结果：跑通"下载 → sample.json"生产链路。
- **CIP 多版本前端**：双子星版（仪器管理、分类导出等）、序源版（字典管理、签发审批等）、商业版（管理面板 + GitHub 开源 + 中英文 README）、宣传网站（VitePress、授权管理、使用文档）；配套说明文档（V1.2.0→V1.9.x）与软著材料；结果：4 月生产版 V1.7.0，10 月 CIP 前端告一段落。
- **FMS 文件管理系统前端**：文件管理（右键菜单、批量操作、预览、打印、全局搜索）+ 权限审批闭环（申请—审批—继承 tag）；结果：9 月前端基本完成。
- **NAP 前端**：引物标签、样本信息、参数管理、任务投递（CMA/NGS/三代 PGT/WES）、任务管理、数据统计等模块 + 通用组件沉淀；结果：12 月个人部分基本完成，teedoc 文档部署。
- **PGS 质控报告运营**：2–11 月逐月交付；难题：单位名称跨月不一致、样本重复 → 总表识别、去重；扩展 NA 率/阴阳性率口径、xlsx 损坏校验；结果：9 月辅助质控报告 2.0 更新，打包更新 GitLab。
- **WES 日常交付**：全年约 50 例次（含携筛、室间质评、新生儿基因筛查）+ 14 例科研样本注释过滤；解决室间质评位点未注释、NEB 基因 Call 不出等问题；沉淀 bam 筛选等工具脚本。
- **其它**：rsID→位点工具封装、PGT-A 汇总统计维度扩展、三代样本 DeepVariant（WGS/ONT）、ExomeDepth CNV 提取、GeneBe 数据库准确性验证（100 位点爬虫比对）、OWMS 官网后台、全年生信数据运维。
